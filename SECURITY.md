# Sécurité

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.
Utilisez plutôt le signalement privé de GitHub : onglet **Security** du dépôt
→ **Report a vulnerability**. Le signalement n'est visible que par le
mainteneur.

Merci d'indiquer la version concernée (affichée en bas à droite du panneau),
les étapes pour reproduire et l'impact estimé. Projet maintenu sur le temps
libre : une réponse est visée sous quelques jours, sans garantie de délai.

## Versions supportées

Seule la dernière release (voir les tags `vX.Y.Z`) reçoit des correctifs.
